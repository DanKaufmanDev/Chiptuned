# Retro Chiptune Audio Generator

This is a simple web-based retro chiptune audio generator.

## How to use

1. Open the `index.html` file in a web browser.
2. Use the controls to select a waveform, frequency, and duration.
3. Click the "Play" button to hear the sound.
4. Click the "Random" button to generate a random sound.

## Files

- `index.html`: The main HTML file.
- `style.css`: The CSS file for styling the page.
- `script.js`: The JavaScript file for generating the audio.
